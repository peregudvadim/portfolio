# Портфолио проектов

Здесь представлены мои учебные и практические проекты, 
реализованные с использованием современных технологий Java и инструментов веб-разработки. 
Каждый проект можно найти на GitHub по соответствующей ссылке.

---

## 📌 [NewsPortal](https://github.com/peregudvadim/NewsPortal)

**Описание:**  
Веб-приложение "Информационный портал" с ролевым доступом для администрирования новостей.

**Основной функционал:**
- Управление новостями с правами администратора
- Аутентификация и авторизация пользователей
- Валидация форм, фильтры, слушатели

**Технологии:**  
`Apache Maven`, `Tomcat`, `JDBC`, `Liquibase`, `MySQL`, `JSP`, `Java Servlets`

## 💳 [Payments](https://github.com/peregudvadim/payments)

**Описание:**  
Система управления клиентскими платежами.  
Клиент может управлять своими счетами и кредитными картами, выполнять пополнения и платежи, а также блокировать счёт. Администратор — разблокирует.

**Основной функционал:**
- Поддержка нескольких карт и счетов на одного клиента
- Проведение и блокировка платежей
- Система ролей: клиент и администратор

**Технологии:**  
`Spring MVC`, `Hibernate`, `JSP`, `BCrypt`

## 📊 [Initech](https://github.com/peregudvadim/initech)

# Описание:**

Сервис для управления бизнес-процессами компании (клиенты, сотрудники, департаменты, контракты, счета, транзакции и платежи). Реализованы CRUD-операции для всех ключевых сущностей с защитой через Spring Security и управлением схемой базы данных через Liquibase.

## Основной функционал:

- Полный CRUD для клиентов, сотрудников, департаментов, контрактов, счетов, транзакций и платежей
- Аутентификация и авторизация через Spring Security
- Маппинг DTO ↔ Entity с помощью мапперов
- Инициализация и миграции базы данных с помощью Liquibase
- Поддержка пользовательских ролей и доступов
- Валидация форм и обработка ошибок
- Разделение на уровни контроллеров, сервисов и репозиториев
- Логирование действий в системе

## Технологии:

- **Spring MVC** - Архитектура для создания веб-приложений.
- **Spring Security** - Управление безопасностью приложения.
- **Spring Data JPA** - Для работы с базой данных через JPA.
- **Liquibase** - Миграции для базы данных.
- **Lombok** - Упрощение кода через аннотации.
- **JUnit 5** - Фреймворк для юнит-тестирования.
- **Log4j 2** - Логирование в приложении.
- **PostgreSQL** - Реляционная база данных.

## Структура сущностей:

- **ClientEntity**: Клиенты компании, с полями для имени, контактных данных и истории заказов.
- **ContractEntity**: Контракты, заключенные между клиентами и компанией, с деталями условий.
- **DepartmentEntity**: Информация о департаментах внутри компании.
- **EmployeeEntity**: Сотрудники компании, их роли и департамент.
- **InvoiceEntity**: Счета, выставленные клиентам.
- **PaymentEntity**: Платежи по счетам.
- **TransactionEntity**: Операции по платежам и транзакциям.
- **UserEntity**: Пользователи системы с ролями и правами доступа.

## Настройка базы данных:

- Миграции с помощью Liquibase для автоматического обновления схемы базы данных.
